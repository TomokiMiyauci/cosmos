# cosmos

Persistence and Protocol Agnostic CMS

A content infrastructure independent of specific databases or delivery methods.

## Features

1. Persistence Agnostic

Supports any storage medium, including Git repositories, file systems, RDBs, and
NoSQL.

2. Protocol Agnostic

Allows for the free selection of delivery protocols such as GraphQL, REST, or
gRPC.

3. Pure Plugin-Based

Persistence, delivery protocols, validation, and transformation—all
functionalities are provided as plugins.
